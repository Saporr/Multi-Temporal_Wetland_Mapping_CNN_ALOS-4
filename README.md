# Multi-Temporal_Wetland_Mapping_CNN_ALOS-4
Multi-temporal Coastal Wetland Classification using ALOS-4 (PALSAR-3) SAR Data with CNN and Random Forest Models.
This repository contains the code used in the study:
"Multi-Temporal Wetland Mapping with ALOS-2 and ALOS-4 SAR Using Deep Learning"

## Contents
- Data preprocessing (Normalization/Crop/Stack Data)
- Feature extraction (sample extraction and train/test sample preparation)
- CNN and Random Forest models

## Data
- Sentinel-2: publicly available from ESA
- ALOS-2/ALOS-4: provided by JAXA EO-RA4 (not publicly available)

## Requirements
pip install -r requirements.txt

## Reproducibility
Sample data and scripts are provided to reproduce key experiments.
